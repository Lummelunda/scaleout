Component Library Primitives · Typography

Type Scale

Display — 80px weight 800. Title slides only. Use h1.

Subtitle — 28px weight 500, primary color. Under display. Use p.

Section label — 22px weight 600, primary color. Use h3.

Body — 20px weight 400, dim color. Supporting prose. Keep to 2–3 lines. Use p.

Callout — 22px, accent color. Border is on wrapper div, not this p. One per slide max.

Caption — 14px muted. Below images or figures only. Use p.

Label — 11px uppercase. Header bars and meta info only. Use span.
